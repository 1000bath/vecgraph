# Contributing to dek-memory

> Workspace-wide policies: [../CONTRIBUTING.md](../CONTRIBUTING.md) and [../SECURITY.md](../SECURITY.md).

Read `CLAUDE.md` for package-specific guidance.

- Use Node.js 24+.
- Add regression tests for retrieval and storage changes.
- Run the evaluation harness when scoring or fusion changes.
- Do not place provider routing or agent session behavior in this package.
